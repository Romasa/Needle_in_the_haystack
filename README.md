# Needle_in_the_haystack
The author of the book "Biostart Handbook" said it well, "Bioinformatics is essentially like finding needle in the haystack". The name of this repository is to give the authors of the book a tribute to coin this quote for bioinformatics. This repository is my own sandbox to learn bioinformatics. Maybe for some other students too. So, let's start!

# Who can use this material?
Anyone who need to learn bioinformatics. Reasons can be diversified, like, course requirement, project completion or establishing of a portfolio for job purposes.

# Pre-requisite
For now, it is assumed that you already have basic knowledge of **molecular biolgy** (Ever heard the name of DNA, RNA? Yes! that's enough). You are assumed to have a good knowledge of **programming** in Python, and or C(++). You are also assumed to know basic **Statisitcs**. Well, a blend of these three subjects put you in a good standing to learn Bioiformatics.

# Are you scared to study bioinformatics?
So am I. This is the rapidly evolving field, but the positive aspect is that, there is much to explore in this field and a promise that this field is not letting to get bored. Exciting challenges and questions are always in your way. This enchanted field is good for those who wants to work in a dimension with open questions.
